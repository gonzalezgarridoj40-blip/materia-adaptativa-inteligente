# Materia Viva (MVJ / Protocolo de Materia Adaptativa)

**Autor y Titular de Derechos:** José Antonio González Garrido  
**Estado del Proyecto:** Prototipo Conceptual y Simulación Lógica  

## Descripción del Proyecto
Materia Viva es un marco conceptual y de simulación para matrices coloidales y materiales adaptativos con microesferas Janus, diseñado para optimizar el almacenamiento térmico y la respuesta estructural frente a estímulos externos.

## Estructura del Repositorio
- `/docs`: Documentación técnica, especificaciones y diagramas del protocolo.
- `/src`: Código fuente en Python para la simulación del comportamiento de la matriz.
